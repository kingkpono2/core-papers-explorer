Good to know

  • CORE treats lowercase and, or and not as operators.
  • Ranges in square brackets, such as [2019 TO 2021], make CORE fail. Use two comparisons instead.
  • CORE ignores an OR group inside other brackets, as in (drone AND (package OR delivery)) AND yearPublished>2019. Brackets around the whole query are removed before searching, so (drone AND (package OR delivery)) works as expected.
  • CORE fails on a search that is only a quoted phrase, such as "drone delivery", so it is sent in brackets: ("drone delivery"). The results are the same.
  • The number of results comes from CORE. For a quoted phrase in a field, such as title:"drone delivery", CORE reports far more matches than really contain the phrase; the best matches still come first.
